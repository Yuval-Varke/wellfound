# wellfound

👋 Hey there, This is Developed to help you Automate the Applying Process at Wellfound.

How to use:

Open the Wellfound Job((https://wellfound.com/jobs)) page
Press F12 or Right-click > Inspect and go to the Console tab.
Paste the script above and hit Enter.

## IMPORTANT - Modify the applicationText variable with your Details as Wellfound excepts this from every application.
